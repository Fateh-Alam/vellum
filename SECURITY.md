# Security and privacy reports

Please report security or privacy issues privately through GitHub's
**Security → Report a vulnerability** flow when available. Do not open a public
issue containing card content, collection data, profile paths, Mind Notes,
handoffs, logs, or a Vellum database.

Vellum does not make network requests and does not use an account, telemetry,
cloud backend, or API keys. A useful report can normally be made with the
redacted diagnostic exported from **Vellum → Settings → Data** plus clear steps
to reproduce the behavior.
